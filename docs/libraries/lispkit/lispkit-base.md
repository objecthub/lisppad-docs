# (lispkit base)

Library `(lispkit base)` aggregates all exported values, parameter objects, and functions from the following libraries and re-exports them.

* [`(lispkit box)`](lispkit-box.md)
* [`(lispkit bytevector)`](lispkit-bytevector.md)
* [`(lispkit char)`](lispkit-char.md)
* [`(lispkit control)`](lispkit-control.md)
* [`(lispkit core)`](lispkit-core.md)
* [`(lispkit dynamic)`](lispkit-dynamic.md)
* [`(lispkit hashtable)`](lispkit-hashtable.md)
* [`(lispkit list)`](lispkit-list.md)
* [`(lispkit math)`](lispkit-math.md)
* [`(lispkit port)`](lispkit-port.md)
* [`(lispkit record)`](lispkit-record.md)
* [`(lispkit string)`](lispkit-string.md)
* [`(lispkit system)`](lispkit-system.md)
* [`(lispkit type)`](lispkit-type.md)
* [`(lispkit vector)`](lispkit-vector.md)
